## What full coverage means

The reference contains all 118 elements for atomic identity and table navigation. Deeper configurations, ion examples, polyatomic species, and any scientific properties cover only the explicitly listed authored subsets. Missing fields are intentional boundaries, not evidence that a property equals zero or that an element lacks it.

The activity bank contains 60 authored cases. It is neither an all-118 exercise bank nor proof every proposed interface mode already works. Coverage is enumerated in coverage_manifest.json and must be regenerated from final records after any change.

## Instructional conventions

State neutral versus ion, ground versus excited state, atom versus molecule/formula unit, isotope versus average element data, and introductory model versus broader chemistry whenever the distinction affects the answer. Common-ion patterns are context-dependent examples. Polyatomic ions retain identity. The full data specification owns notation, charge, configuration, group/layout, unknown-data, and clue-ambiguity details.

Course-specific conventions must be checked with the owner/instructor before automatic grading. Accepted alternative notation should not broaden into accepting a different chemical species. Transparent self-check is appropriate when reliable native evaluation is unavailable.
