## A small reference drawer

For these activities, chloride is Cl⁻, oxide is O²⁻, ammonium is NH₄⁺, carbonate is CO₃²⁻, and sulfate is SO₄²⁻. These selected charges do not list everything these elements can do in chemistry.

In the supplied simple ionic cases, balance the combined positive and negative charges. Keep polyatomic ions intact. A Roman numeral in a variable-charge metal name specifies oxidation state; here it matches the monatomic ion's charge.

In the supplied binary molecular cases, prefixes describe atoms per molecule: mono 1, di 2, tri 3, tetra 4, penta 5, hexa 6. The first element normally omits mono. The second element takes an ide ending. The familiar name dinitrogen tetroxide has contracted spelling; spelling feedback should not erase correct composition reasoning.

## A worked repair if wanted

In Fe₂O₃, three oxide ions contribute −6 altogether. Two iron ions must contribute +6 altogether, so each contributes +3. The name is iron(III) oxide. The subscript 2 still counts iron in the formula ratio; it never became the III.

For ionic formulas, reduce the ratio of whole ions when appropriate. For a molecular formula, preserve the specified atoms in each molecule. Finding an empirical formula is a different task.

## Model boundaries

The bus, gates, voices, and moving cards are fiction. The displayed iron compounds represent extended ionic structures; formula units are bookkeeping ratios, not little isolated molecules. Compound classification must use verified identity and structure when a shortcut is insufficient. Oxidation state is a formal assignment and is not universally an atom's local physical charge.
