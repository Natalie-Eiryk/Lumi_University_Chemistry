# Chemistry Atlas

This subject owns its sources, citations and reference history. The campus owns
the common Atlas validation, query, admission and projection tools.

The existing [reference history](../Luminara_Teaching_Room/30-modules/chem-1117-f2026/ion-language/source/references/history.json)
is retained byte-for-byte, including its existing module and reference IDs. Its
retained backup anchor is included. The campus's `references` commands now resolve
chemistry reads and history writes into this repository; other subjects keep their
own owners. Admission still requires its existing preview and explicit review digest.

[INDEX.json](INDEX.json) locates that authoritative history, the complete content
manifest and the major lesson collections. It is a navigation index, not a second
history database. [MIGRATION.json](MIGRATION.json) records the October 6 custody
transfer from the university commit. No source edition or scientific answer was
changed merely because its repository changed.

Existing Atlas records cover the admitted ion references. The inventory also
locates the other chemistry collections; it does not claim that every worksheet
already has reviewed concept relationships. Expand those through the shared
Atlas's existing contracts as content is reviewed.
