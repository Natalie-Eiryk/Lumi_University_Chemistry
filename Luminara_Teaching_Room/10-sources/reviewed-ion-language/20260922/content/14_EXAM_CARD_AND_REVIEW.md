# The small map to carry into practice

## Exam-sheet candidate — verify permitted scope before use

This is a study reference candidate, not a claim about current exam permission or completeness. The instructor’s current rules control what may be used during an assessment.

### Translation compass

```text
NAME → known ions + charges → minimum neutral ratio → formula
FORMULA → recognize ions → infer variable charge → cation name + anion name

Neutral ionic-formula ledger:  n_c q_c + n_a q_a = 0
Roman numeral: charge per metal ion in these simple salts, NOT atom count.
Subscript: atom/group count, NOT charge.
Repeat a polyatomic ion: use parentheses.
Reduce whole-ion counts; never dismantle an ion’s internal formula.
```

### Pattern or memory?

| Reconstruct | Retrieve as an anchor |
|---|---|
| count ratio from known charges | name + formula + charge of each polyatomic ion |
| metal charge from a known anion and formula ratio | allowed variable-metal states when name/context is absent |
| nitrate → nitrite within the known family | nitrate is NO₃⁻ in the first place |
| selected group-1/group-2 monatomic charges | exceptions and source-specific entries |

### Useful anchors

| Name | Ion | Nearby contrast |
|---|---|---|
| nitrate | NO₃⁻ | nitrite NO₂⁻ |
| sulfate | SO₄²⁻ | sulfite SO₃²⁻ |
| phosphate | PO₄³⁻ | phosphide P³⁻ is a different kind of ion |
| carbonate | CO₃²⁻ | bicarbonate/hydrogen carbonate HCO₃⁻ |
| hydroxide | OH⁻ | -ide does not guarantee monatomic |
| ammonium | NH₄⁺ | ammonia NH₃ is neutral |
| acetate | C₂H₃O₂⁻ | learn the charge with the name |
| oxide | O²⁻ | peroxide O₂²⁻ |
| chromate | CrO₄²⁻ | dichromate Cr₂O₇²⁻ |
| permanganate | MnO₄⁻ | not a chlorine-ladder operation |

Chlorine staircase: **ClO⁻ hypochlorite → ClO₂⁻ chlorite → ClO₃⁻ chlorate → ClO₄⁻ perchlorate**.

Within a known family, -ate has more O than -ite. The suffix alone does not specify charge or a universal O count. -ine is not an ion suffix rule. Common monatomic negative ions use -ide; hydroxide, cyanide, and peroxide show why the reverse inference fails.

### Two checks worth carrying

```text
Fe₂O₃: 3(−2)=−6; 2 irons share +6 → +3 each → iron(III) oxide.
Al₂(SO₄)₃: 2(+3)+3(−2)=0; sulfate stays SO₄²⁻.
```

Sodium peroxide is **Na₂O₂**, not NaO. Magnesium oxide is **MgO**, not Mg₂O₂. Compare ion counts, not just the digits on the page.

## Ten-minute paper session

First minute: write three anchors from memory, then compare with the reference. Next three minutes: one name→formula and one formula→name example, with charge ledgers. Next three: contrast nitrate/nitrite and oxide/peroxide. Last three: repair one incorrect formula and explain what information the name supplied. Stop there; the module does not need to turn every short session into a full exam.

## Speaking rehearsal

Say the name, identify both ions, say their charges, and state the ratio. Example: “Calcium nitrate. Calcium plus two. Nitrate minus one. One calcium, two nitrates. Ca(NO₃)₂.” Then write it without looking.

## Notebook prompts

“What did I derive, and what did I remember?”  
“What remains true if I change the cation?”  
“Which subscript belongs inside the ion?”  
“What extra information would make this ambiguous name solvable?”
