# Practice prompts: the 72-item seed bank

## Use and scope

This is an authored **72-item seed bank**, not a claim about the instructor’s actual exam questions. It supplies representative naming, construction, discrimination, and boundary tasks using the working bank. All questions are original practice. Exact course-bank reconciliation remains pending; see [15](15_SOURCES_AND_DECISIONS.md#src-course-ions).

Answers and diagnostic rationales are deliberately separate in [09](09_ANSWER_KEY.md). The live module should reveal them only on Check/Reveal in study mode. A static client is not a secure exam system; hiding answers in the interface is not secrecy.

The same ID must connect prompt, compiled answer record, hints, skill evidence, and tests. Changing a prompt’s chemical target requires an item version change. Do not randomize between -ate and -ite or Roman numerals without updating the answer record.

## Bank expansion hooks

`BANK-01`: generate one name→formula+charge and one formula+charge→name recall variant for each approved ion. Those are two directions of the same ion skill, not two independent proofs of chemistry mastery.

`BANK-02`: use the curated pair records in the answer key for compound items. Do not generate arbitrary neutral combinations from every cation and anion.

`BANK-03`: generate completion variants by masking a step in a worked example. Record that identities were supplied. Example masking options: anion charge; ion count; Roman numeral; outer parentheses. One mask at a time initially.

`BANK-04`: use explicit misconception distractors, not random strings. Ca(NO₃)₃ tests charge balance; CaNO₆ tests group structure; calcium nitrite tests family identity. Do not present several distractors as though they diagnose the same mistake.

`BANK-05`: keep compound generation a notation exercise. Add no claims about solubility, medical use, reaction yield, or safe preparation.

## Suggested review sets

- Orientation: PR-01, PR-05, PR-10.
- First independent ratio pass: PR-18, PR-20, PR-22, PR-25.
- Group preservation: PR-23, PR-27, PR-28, PR-38, PR-63, PR-70.
- Roman numeral contrast: PR-43, PR-44, PR-45, PR-46, PR-47.
- Family contrast: PR-08, PR-09, PR-11, PR-34–37, PR-68–69.
- Transfer exit: PR-23, PR-34, PR-45, PR-50, PR-62, PR-66, using equivalent fresh variants when these were just taught.

These sets are defaults. Do not expose 72 prompts at once or require perfect scores to access the rest of the lesson.
