# Chemistry: how to use your study desk

Open the existing **Luminara Campus** desktop shortcut, then choose **Start naming
practice** in the Chemistry focus card. Chemistry also has the same prominent
naming links and a **How to study** tab. Keep the installed folder and shortcut;
updates use the existing confirmed version handover. There is no new package to
extract and no new notebook address.

## This week's focus: ions and compound naming

Use a short session of roughly 15–20 minutes. Work through the sessions at your
own pace; repeat a difficult set instead of treating a filled bar as mastery.

| Session | Focus | What to do |
| --- | --- | --- |
| 1 | Ion names, formulas and charges | Learn the rule, answer set 1's six questions, then practise the 12 core ion cards name → formula and charge. |
| 2 | Naming endings and oxygen families | Work set 2, then reverse the core cards: formula and charge → name. |
| 3 | Compound name → formula | Work set 3. Explain the charge balance and keep each polyatomic ion intact. |
| 4 | Formula → name and Roman numerals | Work sets 4 and 5. Explain how the formula constrains a variable-charge metal. |
| 5 | Mixed recall and repairs | Work set 6, then use the shaky/due review. Return to any rule you cannot explain. |

Every study card has **Learn the rule** and **Start 6 questions**. Lessons now
begin with a short study summary; the full supplied lesson and teaching notes
remain available underneath. **Practise this rule** returns to a matching set.

## Use the same routine for questions

1. **Recall:** write an answer before opening the hint or worked answer.
2. **Check:** use **Check my answer** for names/formulas. Explanation prompts use
   **Compare my explanation**, which shows a source response for self-review.
3. **Explain:** say what the charge, ending, subscript or Roman numeral tells you.
4. **Revisit:** mark shaky naming items, save, then return after a break.

Use **Previous question** and **Next question** within the selected set. Switching
sets keeps drafts. After a recorded check, **Start a fresh answer** clears the
answer box for another attempt while retaining the previous check in history.
It does not erase an unfinished draft or remove earlier assistance evidence.

The progress bars count questions with recorded checks, including answers needing
revision. They do not mean every answer is correct or that the topic is mastered.
Both ion-card directions have separate check history. All 72 questions and all
62 provisional ion cards remain available through the set selectors.

## Choose the right Chemistry space

- **Naming practice:** ion names/formulas/charges, compound naming, Roman numerals,
  family comparisons and the existing review queue.
- **Worksheet practice:** the 293 prompts and 561 answer fields replacing the
  19 source entries. Q3 has checked numerical feedback; Q4 has checked factor
  practice. Other sets retain hints and self-review.
- **Try the numbers:** explore a calculation, make a prediction and bring the
  method back to a worksheet question.
- **Topic map, Guided notes and earlier Unit I tools:** retained reference and
  explanation spaces. **Earlier Unit I vocabulary** is distinct from ion naming.

## Save and return

Use the shared **Save** above the subject. If native saving has not been adopted,
review the existing copy/switch dialog first; Cancel leaves browser originals
unchanged. Chemistry and Ion Language retain their existing notebook identities
under the same shared save/journal system. A naming set does not create another
store or cloud-sync channel. Save before following a link to another subject.

**My work** provides the shared journal, backups, recovery and history. Closing
the browser leaves the campus server running; shutdown remains explicit through
the page/tray confirmation. See [Desktop and updates](DESKTOP_AND_UPDATES.md).
