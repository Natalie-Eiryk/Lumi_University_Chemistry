# Session design — reuse what already works

## Not twenty-one lessons for twenty-one rows

The six scenes teach reusable operations. The default route starts with successful structures, then changes one feature. The learner may open any scene directly; do not impose remedial lockouts.

| Stage | Minutes | Teaching action | Observable outcome |
|---|---:|---|---|
| Orient | 3 | Separate the compound-type field from the name/formula field | Learner identifies which field needs attention |
| Naming model | 7 | Q13-SCF-01; contrast CS₂ and a familiar salt | Learner chooses a route and gives a scoped reason |
| Symbol identity | 5 | Q13-SCF-02; P versus K before prefixes | Learner reads PBr₃ without substituting K |
| Whole ions | 8 | Q13-SCF-03; NH₄NO₃ → (NH₄)₂S; Na₂SO₄ → K₂SO₄ | Counts satisfy neutrality without changing the ion |
| Roman numerals | 6 | Q13-SCF-04; NiS and Fe₂O₃ | Charge per metal ion becomes a Roman numeral |
| Prefix counts | 6 | Q13-SCF-05; N₂O₄ versus N₂O₅ and Cl₂O | Prefix reflects actual atom count |
| Boundary cases | 8 | Q13-SCF-06; hydrides, boron, nested ions | Learner refuses an overbroad suffix/position shortcut |
| Return | 5 | Mixed native fields and one explanation | Learner identifies the particular rule used |

Total proposed first pass: **48 minutes**, adjustable. Timing is a design estimate, not evidence of an optimum. Breaks and continuation are permitted.

## Twelve-minute rescue route

- 2 minutes: type/name split with Q13-SCF-01.
- 4 minutes: one complete whole-ion example in Q13-SCF-03.
- 3 minutes: whichever of symbol identity or prefixes a probe indicates.
- 3 minutes: return to the actual field, then a related existing exercise with hints hidden.

The longer reading stays available. A short path must not be framed as a lower-status learning mode.

## Recognition → supported production → independent return

A learner may recognize a term before being able to recall it. Start with a bounded choice when useful. Then reconstruct with ion cards/count tiles; finally type or write an answer. The modes are task supports, not claims that the learner belongs to a fixed visual/auditory/kinesthetic “learning style.”

After a full reveal, use a different but related existing item for a later independent check. Do not count copying the just-revealed answer as established recall.

## Branching by the smallest unresolved step

| First observation | Next question | Helpful branch |
|---|---|---|
| PBr₃ named with potassium | “Which element is P?” | Wrong/unsure → symbol card; correct → naming grammar |
| N₂O₅ given a four-oxygen name | “How many O atoms?” then “Which prefix means five?” | Separate reading count from retrieving word |
| KSO₄ | “Use K⁺ and SO₄²⁻: what is the total?” | Correct −1 → whole-ion count; unsure → charge ledger |
| CS₂ correct but ionic selected | “Which naming route describes this carbon/sulfur example?” | Type-only repair; preserve CS₂ |
| Nickel sulfide | “What charge must nickel contribute against S²⁻?” | Charge known → naming precision; unknown → reverse ledger |
| B₂H₆ labeled ionic | “Does hydride alone specify ionic bonding?” | Boundary contrast with LiH; no new element-charge rule |

These are hypotheses to check, not labels applied to Natalie. One response can result from a slip, an interface action, guessing, a partial rule, or missing understanding.

## Rhythm within each scene

Observe → propose a model → change one feature → explain the friction → pause → name the rule → return.

Each scene contains a Slow Turn. Do not replace the reflection with an immediate answer banner. Keep an optional “My model before / My model now” note with no automatic correctness label. Freeform reflection is private and learner-owned.

## Reinforce successes without overstating mastery

The private worksheet evidence supports using successful examples as bridges: ammonium nitrate, sodium sulfate, potassium carbonate, dinitrogen tetroxide, and bromine trifluoride. That shows a correct response on this page, not proof of permanent mastery. Public scenes use these as ordinary examples without displaying the learner’s history.

## Finish

Ask one question: “What did you change: the element, the naming route, the charge balance, the count word, or only the notation?”

This is the transfer goal. The learner should be able to repair a precise part of an answer rather than erase the entire solution and guess again.
