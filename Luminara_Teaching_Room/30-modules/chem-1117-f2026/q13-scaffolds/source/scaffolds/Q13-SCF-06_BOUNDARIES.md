# Same word, different chemical context

**Scaffold ID:** Q13-SCF-06  
**Primary anchors:** CR-338, CR-341, CR-342  
**Related:** CR-310, CR-325, CR-326, PR-38, PR-62; MAT-08–MAT-13  
**Time:** about 8 minutes; optional deeper material can wait  
**Model change:** “A suffix or periodic-table location gives a universal category” → “A clue has a scope; constituent identity and chemical context choose the naming model.”

## 1. Teaching scene — the hydride badge does not open every door

Two model cases carried the word **hydride**. One displayed **LiH**. The other displayed **B₂H₆**.

**Natalie:** “We just learned hydrogen can be H⁻ in lithium hydride. So when I saw another hydride, I reached for the same model.”

**Ms. Luminara:** “A reasonable transfer to try. Now let us test its boundary.”

She opened the LiH case. Its solid-state teaching model used **Li⁺** and **H⁻** as ionic constituents.

The boron-hydride case did not break into an equivalent ion lattice. It stayed a covalent molecular model.

**Henry:** “Same ending, different bonding context.”

**Kàra:** “Then hydrogen’s position above the alkali metals is not a promise that it behaves like lithium.”

**Ms. Luminara:** “Exactly. A useful example does not become a universal law because we remembered it successfully.”

Natalie opened her notebook.

**Natalie:** “For B₂H₆, the type is covalent. The count-prefix name is diboron hexahydride: two B, six H. The familiar name is diborane.”

**Ástríðr:** “And ‘boron hydride’ was not a meaningless phrase. It was less specific about the counts the exercise wanted.”

**Ms. Luminara:** “Yes. That phrase is used as a synonym in chemical records. In a prefix exercise we still make the requested counts explicit. We distinguish naming convention from inventing a different substance.”

Carlos looked at a third case labeled **NH₄NO₃**.

**Carlos:** “No metal. So that one must go through the molecular door?”

**Jeff:** “Wait. Identify the passengers before opening it.”

The case highlighted two complete groups: **NH₄⁺** and **NO₃⁻**. Inside each group, shared-electron bonds were visible in the teaching representation.

**Jackson:** “Covalent connections inside each ion. Positive and negative ions at the compound level.”

**Ms. Luminara:** “So ammonium nitrate uses the ionic naming route. We must name the boundary of the question.”

**Natalie:** “I was looking for one visible clue that would always decide: metal, no metal, hydride, or a subscript.”

**Ms. Luminara:** “And those clues help until they overreach. A recognized chemical identity lets you choose the model; the model then tells you which arithmetic is relevant.”

## 2. A bounded comparison wall

| Case | Introductory description here | Naming consequence |
|---|---|---|
| LiH, ordinary solid | Li⁺ and H⁻; ionic hydride model | lithium hydride; no molecular prefix needed |
| B₂H₆ | covalent boron hydride | diboron hexahydride for count-prefix practice; diborane common |
| BF₃ | molecular boron halide | boron trifluoride; covalent type |
| NH₄NO₃ | ammonium and nitrate ions; covalent bonding within groups | ammonium nitrate; ionic type |
| Na₂O₂ | sodium ions and peroxide groups | sodium peroxide; preserve O₂²⁻ |

The LiH comparison is a scientific extension from the earlier discussion, not a new Q13 worksheet row. Do not assign it an existing CR ID or treat it as a completed course response.

## 3. What not to infer

- **No metal → always molecular** fails for ammonium salts.
- **Metalloid → always ionic** fails for these boron compounds.
- **Hydride → always a salt of H⁻** fails as a universal rule for hydrogen compounds.
- **Neutral → ionic** fails because neutral molecules also exist.
- **Covalent bonds anywhere → whole compound must use molecular prefixes** fails for polyatomic-ion salts.
- **A balanced formula must be a known stable substance** also fails; balancing is a constraint, not an existence proof.

The supplement does not attempt to classify every compound from element names alone. Network solids, unfamiliar compositions, mixed oxidation states, and special nomenclature need their own supported handling. “Needs more context” is a valid app outcome.

## 4. Under the Floorboards — model scope, not a magic threshold

Bonding descriptions are approximations to an electron distribution and structure. A useful ionic model emphasizes charged constituents and their electrostatic interactions; a covalent model emphasizes shared electron density. IUPAC recommends considering degree of ionic character rather than treating perfectly ionic and perfectly covalent as exhaustive physical boxes. Do not make one electronegativity-difference threshold the final classifier.

For B₂H₆, the full bonding explanation is more advanced than the present naming task. Leave that as optional future content rather than drawing six identical isolated B–H single bonds and calling the structure explained.

## 5. The peroxide lock

Place **2 Na⁺ + 1 O₂²⁻** on the whole-ion ledger. The total is zero and the ion ratio is already smallest. A “reduce Na₂O₂ to NaO” button would destroy the peroxide group’s composition, not simplify the same conventional salt formula.

This is a separate safeguard from not reducing N₂O₄. The common principle is **preserve the chemical entity represented**; the specific reasons differ: polyatomic-ion identity in one case, molecular atom count in the other.

## 6. Codex hook and naming-review gate

Use the existing supported compound record before generic heuristics. Allow an explicit uncertainty state instead of forcing every unfamiliar formula into two categories.

For B₂H₆, treat these dimensions separately:

- type: covalent in this exercise;
- requested prefix construction: diboron hexahydride;
- recognized common name: diborane;
- recognized broader synonym: boron hydride;
- instructor acceptance of alternatives: not established by the supplied snapshot.

A synonym may receive “recognized identity; requested form uses prefixes.” That is not permission to silently change the native checker or to mark a disputed classroom variant as definitively instructor-approved.
