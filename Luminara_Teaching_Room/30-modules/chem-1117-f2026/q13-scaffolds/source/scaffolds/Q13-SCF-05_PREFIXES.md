# Count before you pronounce

**Scaffold ID:** Q13-SCF-05  
**Primary anchors:** CR-305, CR-307, CR-311  
**Related:** CR-226–CR-235, CR-331, CR-332; L06; MAT-13  
**Time:** about 6 minutes  
**Model change:** “Choose a familiar-sounding compound name” → “Translate each stated atom count into the corresponding word.”

## 1. Teaching scene — the loom adds one oxygen

Two tags hung above adjacent model displays:

**N₂O₄** and **N₂O₅**.

Natalie read the first.

**Natalie:** “Dinitrogen tetroxide.”

Ms. Luminara covered the name and uncovered the second formula. Its oxygen inventory had one additional token.

**Ms. Luminara:** “What changed?”

**Henry:** “Then only one count word should change.”

Natalie found **penta-** on the prefix strip.

Kàra watched the nitrogen count remain fixed.

**Kàra:** “We are not adjusting the formula to balance nitrogen and oxygen ions?”

**Ms. Luminara:** “No. This naming task gives us the composition. We report it. Rebalancing it would answer a different question.”

The next tag read **Cl₂O**.

**Natalie:** “Two chlorine, one oxygen. Dichlorine monoxide.”

**Carlos:** “Does the one always disappear?”

Ms. Luminara moved a **CO** tag alongside it.

**Ms. Luminara:** “For this introductory prefix convention, we usually omit mono- on the first element. We retain it on the second when it is needed: carbon monoxide, dichlorine monoxide.”

Jeff looked at a switch marked **REDUCE ALL NUMBERS** and placed a cover over it.

**Jeff:** “Nobody touches that while we are reading molecular formulas.”

**Natalie:** “A prefix is a little written count. If I get the count right but the word wrong, I need the prefix map. If I read the count wrong, I need to look back at the formula. Those are not the same problem.”

**Ms. Luminara:** “Good. That is how the help should find you, too.”

## 2. Count → prefix → name

| Atoms | Prefix | Atoms | Prefix |
|---:|---|---:|---|
| 1 | mono- | 6 | hexa- |
| 2 | di- | 7 | hepta- |
| 3 | tri- | 8 | octa- |
| 4 | tetra- | 9 | nona- |
| 5 | penta- | 10 | deca- |

| Given formula | First count | Second count | Target prefix-style name |
|---|---:|---:|---|
| Cl₂O | Cl = 2 | O = 1 | dichlorine monoxide |
| PBr₃ | P = 1 | Br = 3 | phosphorus tribromide |
| N₂O₄ | N = 2 | O = 4 | dinitrogen tetroxide |
| N₂O₅ | N = 2 | O = 5 | dinitrogen pentoxide |
| P₂O₃ | P = 2 | O = 3 | diphosphorus trioxide |

These are naming exercises on the **given formulas**. A formula token is not a full molecular-structure claim; keep the original phosphorus-oxide notation rather than silently replacing it with a different formula.

The prefix route is not for ordinary ionic ratios: do not convert MgCl₂ into “magnesium dichloride” in this course’s ionic-naming task merely because a two is present.

## 3. Sound, text, and exact counts

Have the learner say or type the counts before the assembled name: “two nitrogen, five oxygen.” Offer the prefix strip only after the count is identified. A text alternative must always be present.

Spelling is a separate layer. Monoxide, tetroxide, and pentoxide are the forms used in the examples here. Do not hard-code “delete every vowel before oxide.” The inventory says the complete instructor spelling convention remains unresolved. A correct count with a recognized alternate contraction must receive an explicit convention note, not be treated as a counting failure.

## 4. Do not reduce the information away

N₂O₄ and NO₂ have the same simplest atom ratio, but different molecular formulas. Reading a given molecular formula is not a greatest-common-divisor exercise.

Similarly, the 2 and 5 in N₂O₅ count atoms. They do not direct the learner to assign N²⁺ and O⁵⁻. Subscripts and charges occupy different roles.

## 5. Guided and independent returns

- Show the N₂O₄/N₂O₅ pair with only one oxygen changing.
- Hide the prefix strip, but keep atom counters.
- Hide counters and return to CR-311.
- Later open native CR-230 (five → penta-) and a separate molecular-name field such as CR-237. Do not store these as duplicated new questions.

## 6. Codex hook

**Probe order:** read the subscript → select the count prefix → assemble the name → check conventional spelling.  
**Feedback for the submitted pattern:** “Dinitrogen keeps the two nitrogen atoms. This formula has five oxygens, so the oxygen count needs penta-, giving pentoxide in this naming convention.”  
**Do not infer:** that a single tetra-/penta- error proves the learner forgot all prefixes.  
**Rendering:** show subscripts in display, plain digits in an editable input if the existing app does so, and preserve the chemical identity on round-trip.
