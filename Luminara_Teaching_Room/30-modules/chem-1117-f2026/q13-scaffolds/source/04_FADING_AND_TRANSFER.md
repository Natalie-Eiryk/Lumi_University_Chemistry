# Practice without rebuilding the question bank

## Existing exercises remain the return points

The activities below use the current CR/PR fields. They are not new assessment IDs. A worked scaffold can reveal the mechanism; the native exercise remains where the learner chooses or types an answer.

| Focus | Supported encounter | Less support | Later native return |
|---|---|---|---|
| Type versus formula | Show CS₂ and its correct name; classify only | Same for BF₃ without the explanation | CR-330, then CR-338 |

“Later” means a separate return chosen by the learner or the existing scheduler, not a promise of background reminders.

## Three ungraded formats for every return

### 1. Notice-and-choose

Offer a small set of meaningful alternatives with the periodic table or ion card visible. The learner may ask for a hint without losing credit elsewhere.

### 2. Build-and-explain

Use count tiles or an equation. The learner identifies which number belongs to atoms, whole ions, or charge. A text-only route must accomplish the same task.

### 3. Recall-and-check

Hide the aids initially. Accept typed formulas in the app’s supported syntax and render them chemically alongside the entry. Explanations remain optional private reflection unless an appropriate reviewed rubric exists.

These are different task demands. Correct recognition, assisted reconstruction, and unaided recall must not be collapsed into one mastery score.

## A six-minute mixed return

Open the existing fields in this order, with no new duplicated prompt bank:

1. CR-307 — PBr₃ name.
2. CR-313 — potassium sulfate formula.
3. CR-303 — NiS name.
4. CR-311 — N₂O₅ name.
5. CR-330 — carbon disulfide type.
6. CR-342 — B₂H₆ type.

Each asks a different decision. A mistake should offer the matching scaffold, not restart all six. No timer is required; six minutes is an estimate, not a cutoff.

## Self-review targets, not a replacement key

The scenes explain these targets: phosphorus tribromide; K₂SO₄; nickel(II) sulfide; dinitrogen pentoxide; covalent; covalent. The native configured answers still determine the actual feedback fields. If a target conflicts with the live reference, show a source-review warning rather than silently overwrite either source.

## Suggested future review policy

Use existing spaced-review facilities when present. A reasonable initial design is a short return later in the session, the next study day, and several days later, adjusted by actual performance and learner choice. This schedule is proposed, not empirically individualized or automatically scheduled here.

A reveal should leave a trace such as “reviewed with help,” not a forced “failed.” The learner may practice familiar successes to regain continuity. Do not permanently brand a topic mastered or weak after one response.

## Carry-forward prompt

> “Which part became clearer: the symbol, the constituent ion, the number of copies, the prefix, the Roman numeral, or the type label?”

Store that answer only in the existing learner-controlled note space. It can direct the next scaffold without becoming a diagnosis.
